# Java-aws-enterprise

This project will demonstrate an enterprise Java architecture on AWS. It aims to showcase common patterns for building scalable services with AWS.

## Objectives

- Provide reference implementations for microservices in Java.
- Demonstrate integration with AWS services such as EC2, S3, and RDS.

## Build

1. Install Maven and JDK 11 or later.
2. Run `mvn clean package` to build the project.

More usage instructions will be added as the project evolves.
